# v0.3.0 验证报告

2026-11-06 UTC，验证内置VLESS、可选下载、IP复制、移除DMIT选择和扩大任务规模。原始日志保存在运行工作区忽略提交的`test-artifacts/`，节点凭据未写入源码、报告或发布包。

## 内置VLESS实现

内置Go客户端支持VLESS WS+TLS与普通TCP+TLS。只替换候选IP:端口，保留模板UUID、SNI、Host与路径；不需要外部sing-box/Xray。WebSocket帧处理使用Gorilla，VLESS协议按公开编码实现。

本机真实TLS/WS/VLESS服务的测试覆盖：

- 两种传输完成通道内HTTPS请求，正确保留SNI、Host、路径和目标地址。
- 通道内读取CF Trace并校验字段，返回成功轮数、TTFB与出口IP。
- 通道内限量下载，记录实际字节数与耗时。
- 错误UUID和错误VLESS响应版本失败，未直连回退到HTTPS目标。
- 外层关闭证书校验时，内层HTTPS仍会拒绝不可信证书。
- 取消请求及时中止通道，下载开关关闭时下载函数调用次数为0。
- 模板保存后可以重新打开任务目录并继续；下载选择保持不变，VLESS成功计入命中数，日志重载后计数一致。
- 创建、列表和详情返回隐藏模板；结果JSON/CSV不含模板。为支持续扫，本机任务文件保留明文凭据，备份包含凭据。

## 用户指定三个IP的真实请求

保持用户提供的VLESS WS+TLS模板参数，仅替换地址为154.17.13.209、64.186.251.83和154.17.7.120，端口443。模板UUID、业务域名与路径不公开。

1. **仅真连接、关闭下载**：每个候选2轮，三个候选均为2/2、HTTP200并取得有效Trace；结果中没有下载记录。
2. **CF初筛+内置VLESS+开启下载**：三个候选均通过CF双域名Trace、VLESS通道内HTTPS请求和1MiB通道下载。下载标记为`via=vless`，没有使用直连测速替代。
3. **网页提交任务**：在浏览器粘贴模板，填写三个候选、1000000并发、速率0、5000000任务上限，关闭下载。实际worker不超过3个待测候选，三个均通过真连接；接口和DOM不回显模板。

这些测试均使用IPData-WEB自身客户端，没有启动外部代理核心。测量发生在当前Linux测试机，不代表用户Windows电脑或其他网络的速度，也不是长时间稳定性或持续带宽结论。

## 任务规模和不限速

- `/15`网段加两个端口正确计为262144个目标，超过原单CIDR/单任务限制。
- 将任务上限调高后，`/8`加两个端口正确计为33554432个目标，可以直接创建为暂停任务；未展开完整地址列表，未进行任何该范围的网络扫描。
- 重叠CIDR、重复IP、IPv4映射IPv6地址合并去重；UTF-8 BOM可被处理。
- 不可承载的巨大IPv6范围在计数阶段根据任务上限拒绝，不进入逐地址展开。
- 并发1000000000和速率1000000000000可通过参数校验，小样本不会生成超过目标数量的worker；速率0不设限速器等待。
- 极高正速率不会创建零间隔ticker；有限速等待可响应取消。
- 正常运行按需生成目标；暂停续扫跳过日志中已完成的目标。结果仍保存在内存并逐条落盘，因此实际可承载规模取决于资源。

## 浏览器与兼容性

Chromium验证通过，覆盖：

- 手动输入创建VLESS任务，真连接通过筛选与延迟排序。
- 可选下载开关及输入项启用/禁用，保存后恢复原选择。
- IPv4的IP:端口按钮复制纯IP，点击不触发行详情；IPv6兼容复制方式不包含方括号/端口。
- 任务列表与详情不含模板UUID，打开历史任务不会将凭据填入DOM。
- 内置DMIT选择元素不存在，`/api/providers/dmit`返回404。
- 并发与速率HTML输入没有固定max，速率0可提交。
- 桌面与手机视口截图，页面脚本错误为0。

CF域名标签改为“CF初筛SNI/Host”和“CF第二域名SNI/Host”。`one.one.one.one`仅参与CF复验，VLESS使用模板业务参数；仅测VLESS时这两个输入禁用。入口和模板出口无需相同地区，程序没有地区绑定筛选。

## 构建与回归

完整`go test -race ./...`、Linux `go vet`通过；Windows目标静态检查及amd64/arm64交叉构建，发布包检查PE架构、ZIP和SHA256。

既有真实子进程SIGKILL恢复流程继续验证：1/8暂停、2/8强制终止、重启恢复2条、完成8/8，CSV8条，无重复已完成目标。Windows使用同一Go引擎，但当前尚未在原生Windows电脑上实机运行。

CSV中的`success/rounds/median_ms`保留CF指标；`vless_success/vless_rounds/vless_median_ms`为真连接指标；`speed_via`区分候选HTTPS和VLESS通道。下载Mbps以正文读取时间计算，完整总耗时另存于证据，不与v0.2.0外部核心报告中的含握手折算速度混为一谈。
