# v0.4.0 批量节点导出与电脑端UI验证

2026-11-06 UTC。本轮没有为导出功能发起公网扫描或下载；真实导出使用既有三个下载成功的任务记录，IPv6、失败记录和分页使用明确标记的合成测试任务。

## 节点导出

- 使用任务已保存的VLESS模板，实际导出三个节点。仅替换服务器IP和端口，UUID与原始查询参数未改变。
- 可选择当前筛选、已勾选或任务全部下载成功结果；只接受完整下载成功、字节数和速度有效的结果。
- 未测速、失败/不完整下载、零速率、非有限速率不进入导出。勾选项不能注入任务外的任意地址。
- 自动按IP:端口去重；同IP不同端口可分别保留。
- 合成结果验证192.0.2.1:8443替换模板原443端口，以及IPv6分享链接的方括号格式。
- 自定义模板的UUID、SNI、Host、路径、扩展查询参数和原始转义保持；可追加地址到备注，或保留原备注。导出不会改写原任务模板。
- 512条合成成功记录：界面最多显示500行，当前筛选可导出完整512条；全选当前显示页再导出时为500条。
- 统计预览不返回凭据。节点TXT为用户主动导出，包含模板认证信息；普通结果CSV/JSON和任务列表仍不含模板。
- 模板输入在关闭导出、折叠导出面板或切换任务时清空。导出接口仅接受JSON POST，保留原有同源检查和no-store响应头。

## 桌面界面

按用户指定ui-design-iteration执行，详见[UI审查](ui/desktop-review.md)和[设计约定](../design/desktop/design-contract.md)。仅面向电脑端，审查1024/1280/1440/1920px，28种宽度/状态组合未出现页面溢出、对比度失败、未知对比度或脚本错误。

已验证：历史任务/配置折叠、真实下载计数、结果筛选排序、仅成功项可勾选、预览数量、IPv4/IPv6复制、保存模板导出、自定义模板导出、清空选择、键盘打开/Esc关闭及返回焦点。轮询不再销毁当前行焦点；阻止localStorage时也可启动。静态稿离线打开不发HTTP请求。
